# VORTEX-X — Zero-Cost CODM Ping Booster (Android)

اپ بوستری برای کاهش تاخیر کالاف دیوتی موبایل با معماری: **Rust (NDK) + C++ JNI + Kotlin VpnService + Compose**.

## ساخت APK بدون کامپیوتر قوی (GitHub Actions — کاملا رایگان)
1. یک مخزن جدید در GitHub بساز (مثلا `VortexX`) و همه فایل‌های این پوشه را آپلود کن.
2. تب **Actions** → اجرای خودکار «Build Vortex-X APK» شروع می‌شود (~۱۵ دقیقه).
3. پایان بیلد: **Summary → Artifacts → Vortex-X-Pro-apk** دانلود کن.
4. لینک مستقیم دائمی: یک تگ بزن و پوش کن:
   ```bash
   git tag v1.0.0 && git push origin v1.0.0
   ```
   سپس لینک مستقیم APK این شکل می‌شود:
   ```
   https://github.com/<نام-کاربری>/<نام-مخزن>/releases/latest/download/Vortex-X-Pro.apk
   ```

## ساخت محلی (اختیاری)
- Android Studio (Hedgehog+) → Open → این پوشه → Run.
- نکته: بیلد محلی به Rust/cargo-ndk و NDK 26 نیاز دارد؛ ساده‌ترین راه همان Actions است.

## مجوزهای لازم در اولین اجرا
1. مجوز VPN (دیالوگ سیستمی اندروید) — با دکمه BOOST
2. مجوز موقعیت مکانی — برای رادار دکل (الزام اندروید برای CellInfo)
3. اعلان‌ها — برای سرویس پیش‌زمینه

## یادداشت مهندسی (شفاف)
- موتور شبکه: تونل `hev-socks5-tunnel` (MIT) + سرور SOCKS5 داخلی با سوکت‌های protect شده.
- قابلیت‌های واقعی: DSCP EF روی سوکت‌های رله، قفل اولویت کرنل (SO_PRIORITY=6 + IP_TOS)،
  قفل Wi-Fi کم‌تاخیر، پالس 5G با دریچه نرخ ۳ ثانیه، تونل فقط برای کالاف دیوتی، پینگ زنده واقعی (RTT با انتظار پاسخ).
- محدودیت واقعی: DSCP روی مسیر اینترنتِ اپراتور معمولا بازنویسی/نادیده گرفته می‌شود؛
  تضمین «۱۰۰٪ ضدبن» فنی ناممکن است — تونل مسیر عادی UDP/TCP است و پکت بازی را تغییر نمی‌دهد.
